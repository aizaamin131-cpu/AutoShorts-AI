# AutoShorts-AI
AutoShorts AI

AutoShorts AI is a local video-to-shorts generator that transforms long-form videos into vertical short-form content with AI-powered processing.

Features

- Automatic video clip extraction
- Speech-to-text transcription
- Vertical (9:16) video formatting
- Caption generation
- CPU-compatible processing
- Simple web interface

Tech Stack

- Python
- Flask
- FFmpeg
- OpenCV
- Faster-Whisper

Project Structure

AutoShorts-AI/
├── pipeline/
├── static/
├── templates/
├── app.py
├── requirements.txt
├── README.md
└── research.md

Installation

pip install -r requirements.txt

Run

python app.py
